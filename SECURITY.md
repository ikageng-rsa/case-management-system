# Security Policy

## Supported Versions

Security fixes are applied immediately to both `main` and the active `release/{app}-{version}` branch
— not one now and the other later. See "Security Patches" in `CONTRIBUTING.md` for the exact
process. Older releases are not patched.

## Reporting a Vulnerability

Do not open a public GitHub issue for a security vulnerability.

Report privately via the repository's Security tab → "Report a vulnerability", or by emailing
`97877770+ikageng-rsa@users.noreply.github.com`.

Include: what you found, steps to reproduce, and the potential impact. Expect acknowledgement
within 2 business days.
